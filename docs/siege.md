# Осады

Осада — механика, заменяющая «взрывы ломают блоки». Постройки внутри привата
целы, пока цела **прочность ядра**.

## Как это работает

1. Взрыв происходит достаточно близко к ядру → с ядра снимается 1 прочность.
2. У ядра есть кулдаун урона — стак ТНТ не снесёт приват за один тик.
3. Прочность дошла до нуля → приват уничтожен, ядро выпало на пол.
4. После атаки действует **штраф**: починка (прокачка) дорожает на время.
5. Несколько секунд после атаки приват считается «под осадой»: тревожная
   голограмма, плейсхолдеры показывают осаду, сделки и расширение границ
   можно запретить.

Взрывы защищённых блоков внутри привата отдельны от осады — за них отвечает
флаг `explosion_damage` (по умолчанию выключен: взрывы блоки не ломают,
но тратят прочность).

## siege.yml

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `enabled` | true | Главный выключатель: могут ли взрывы снимать прочность |
| `damage_cooldown_ticks` | 20 | Сколько тиков после удара ядро не получает нового урона (20 тиков = 1 сек) |
| `explosion_damage_radius` | 4 | Взрыв вредит ядру, только если его центр ближе этого радиуса (блоков) |
| `penalty_time` | 300 | Сколько секунд после атаки дорожает починка |
| `penalty_multiplier` | 2 | Во сколько раз дорожает починка при штрафе |
| `damage_indicator` | true | Всплывающие цифры урона над ядром |
| `neighbour_alert_radius` | 48 | Кому из соседей слышно, что рядом рейд (0 — не сообщать) |
| `window_seconds` | 300 | Сколько секунд приват считается «под атакой» |
| `deny_core_break_under_attack` | true | Владелец не может снести ядро, пока окно атаки не закрылось |

## Переопределения на тип (regions.yml)

- `raid_immune: true` — тип вообще неуязвим для взрывов;
- `damage_cooldown_ticks` / `explosion_damage_radius` — свои значения
  (`-1` — брать из siege.yml);
- `explosions.TNT|WITHER|CREEPER|ENDER_CRYSTAL|BED` — каким видам взрывов
  разрешено вредить ядру этого типа. Например, «большой» приват можно
  сделать уязвимым только для ТНТ, а «элитный» — полностью иммунным.

## Что видят игроки

- **Звуки**: `raid_attack` при ударе по ядру, `raid_destroyed` при падении
  привата, `raid_nearby` для соседей (visuals.yml → `sounds`).
- **Голограмма**: переключается на `hologram_lines_under_attack`, пока идёт
  окно осады (regions.yml).
- **Уведомления**: владелец (и все с эффектом `ALERTS`) получают сообщение
  в чат; соседям в радиусе `neighbour_alert_radius` — звук и уведомление.
- **Штраф**: в меню прокачки показывается множитель `%penalty%`.
- Сделки (`/ps sell`, `/ps buy`, аренда) можно запретить на время осады:
  `market.sell.allow-during-siege` (features.yml).

## Живучесть штрафа

Штраф — не таймер в памяти, а дедлайн, записанный у привата в базе,
поэтому он **переживает рестарт сервера**. Сломанное и заново поставленное
ядро штраф тоже не обнуляет:

- при поломке остаток штрафа и время последней атаки пишутся в PDC
  предмета ядра (настройка `settings.transfer-penalty`, config.yml);
- предмет лежит в сундуке или в руках — дедлайн всё равно тикает по
  настенным часам, при установке приват получит только остаток;
- на время окна атаки снос ядра запрещён
  (`siege.deny_core_break_under_attack`); игроки с обходом защиты
  ограничение не замечают, но предмет они тоже получат со штрафом.

## Уведомления в мессенджеры

Настраивается в features.yml → `notifications`: Discord-вебхук,
Telegram-бот и DiscordSRV. Сообщение уходит, когда у привата с эффектом
`ALERTS` снимают прочность; одинаковые уведомления шлются не чаще раза
в 15 секунд. Подробнее — [Интеграции](integrations.md#уведомления).
