# 🪨 QweProtectStones — документация

**Приваты на блоках-ядрах для Paper 1.21+** (работает и на Folia тем же jar-ом).
Прочность и осады, рынок и аренда, эффекты, голограммы, пять уровней доверия,
17 флагов защиты, анимированные GUI — без WorldGuard и ProtectionStones.

Игрок ставит блок-ядро — вокруг возникает защищённая территория. Взрывы не ломают
постройки, но снимают прочность ядра; прочность кончилась — приват пал. Прочность
качается за ресурсы, внутри можно купить постоянные эффекты, а сам приват —
продать или сдать в аренду.

## Принципы плагина

- **Ничего не зашито в код.** Каждый звук, тайминг, лимит и требуемый уровень
  доступа вынесен в конфиги. Отсутствующие значения берутся из встроенных
  значений по умолчанию — старые конфиги продолжают работать.
- **Без обязательных зависимостей.** Всё опционально: голограммы, экономика,
  карта, плейсхолдеры. Без них плагин просто чуть скромнее выглядит.
- **Производительность.** Поиск привата по координате — O(1) через чанковый
  индекс; запись в базу — асинхронная, пакетами; меню перерисовываются только
  при реальном изменении привата.
- **Мультиязычность.** Русский, английский, испанский, китайский
  (`settings.language` в `config.yml`). Все тексты — MiniMessage.
