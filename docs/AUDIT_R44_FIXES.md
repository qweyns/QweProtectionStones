## Важные изменения поведения

- **QweTnts/API:** синхронный `damageRegion` на Folia вызывается только в потоке ядра. Для другого потока — `damageRegionAsync`; не вызывать `join()`/`get()` на серверном тике. Классификатор получает и взрывы вне привата при включённой осаде. Множитель ограничен 100, итоговый радиус — 256 блоков. Подробности обновлены в [DYNAMITE_ADDON_API.md](DYNAMITE_ADDON_API.md). Репозиторий аддона не изменялся.
- **Меню:** в платной цепочке разрешена одна выдача эффекта или одна необратимая команда; все списания — перед ней. Сообщения/звук/открытие меню допустимы после выдачи. Произвольные внешние команды не являются откатываемой транзакцией: после их запуска автоматический возврат не выполняется. Штатные цепочки effects.yml соответствуют правилу.
- **Голограммы:** на Folia принудительно используется NATIVE. DH/FH остаются на Paper: одного внешнего API недостаточно для гарантии Folia-безопасности провайдера.
- **Backup/restore:** новые автоматические и внеплановые backup лежат в `backups/`; `/qps export` — в `exports/`. Старые файлы не перемещаются/не удаляются. `/qps restore` находит обе папки.
- **SQL-recovery:** `storage-recovery.yml` содержит ещё не подтверждённые изменения, включая удаления. Его нельзя удалять «для очистки». При невозможности replay запуск защиты прекращается, а журнал сохраняется. Повтор после неоднозначного ответа БД может продублировать строку журнала действий, но не должен повторять Vault-платёж: деньги вообще не воспроизводятся из recovery.

## Границы гарантий

1. Выполнены изменения кода и CI-тесты, **не** игровая сертификация Paper/Folia. Исходная серверная матрица из AUDIT_R44.md остаётся обязательной перед production.
2. Bukkit-плагины обязаны соблюдать MONITOR: отменять/менять событие на этом приоритете нельзя. Отмена до MONITOR учитывается; чужое нарушение контракта не компенсируется магически.
3. Аварийный журнал записывается при flush/остановке, а не fsync на каждое игровое действие. SIGKILL/обрыв питания до flush, отказ диска и неопределённый результат стороннего Vault-провайдера не дают гарантии exactly-once. При отказе компенсации есть явный SEVERE для ручного разбора.
4. Прямые изменения живого Region сторонним аддоном в обход QpsApi/RegionManager/сервиса не образуют транзакцию. Снимки/резервации защищают штатные пути QPS; аддоны должны использовать API и соблюдать потоки.
5. Горячий unload/reload плагина на Folia не является поддерживаемым способом обслуживания. Нужен полный restart. При shutdown чужие инвентари закрывает сервер, NATIVE TextDisplay непостоянны и не записываются в мир.
6. Этот набор закрывает подтверждённые причины из O01–O17; он не означает построчного аудита всех остальных 128 исходных файлов и всех сторонних интеграций.
